# M0.1 work package — repository scaffold

## Goal

Create the smallest buildable private Go skeleton required by ROADMAP M0.1. This package establishes module/package/CI structure only; it must not implement daemon, IPC, store, doctor, simulator, deletion, or LaunchAgent behavior.

## Source requirements

- `docs/ROADMAP.md:14-32` defines M0 and the literal mechanical gate.
- `docs/ARCHITECTURE.md:1-5` requires Go 1.23+, no cgo, macOS 14+, and one `simurgh` binary.
- `docs/ARCHITECTURE.md:260-277` requires race tests and Staticcheck in CI.
- Closed source: add no license file, telemetry, public remote, publishing, release, or package-registry configuration.

## Implementation constraints

- Module path: `github.com/RoshanDewmina/simurgh`.
- `go.mod` minimum language version: Go 1.23.
- `cmd/simurgh` may print a clearly pre-v0 placeholder/help line, but must contain no fake feature behavior.
- CI must run build, vet, race tests, and Staticcheck. Include a stubbed macOS job suitable for later `[mac]` integration gates.
- Package stubs should be idiomatic package documentation only, with no speculative APIs or compatibility shims.
- Tests are waived for this scaffold because it contains no behavior; compilation, vet, race invocation, and Staticcheck are the feedback loop.

## Acceptance commands

Run from the worktree root and include verbatim output in the final JSON response:

1. `gofmt -w cmd internal`
2. `go build ./...`
3. `go vet ./...`
4. `go test -race ./...`
5. `$(go env GOPATH)/bin/staticcheck ./...`
6. `git diff --check`

Also report `git diff --stat` and confirm no file outside the exact write-set changed.

`low` — scaffold only. Any socket, filesystem deletion, simulator mutation, or LaunchAgent implementation is out of scope and would reclassify the work as sensitive.
