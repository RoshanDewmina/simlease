# M0.2b work package — daemon socket, `daemon.ping`, client auto-start

## Goal

Implement the socket/daemon-process portion of M0.2: a Unix domain socket
listener owned by `simurghd`, wired to the M0.2a IPC protocol, dispatching
exactly one method (`daemon.ping`), plus a client dial helper that
auto-starts the daemon as a subprocess on connection failure and retries
once. LaunchAgent installation, `launchctl kickstart`, `daemon install`,
`daemon status`, and `daemon stop` are explicitly out of scope for this
package — see "Explicitly out of scope" below.

## Exact write-set

- `internal/ipc/socket.go` (new) — follow `internal/store`'s injected-path
  convention (see `internal/store/store.go` `New(path string)`): `Listen(path
  string)` takes an explicit socket path (tests inject `t.TempDir()`; it must
  never resolve `~/.simurgh` itself or read env vars) returning a
  `net.Listener` with the socket file chmod'd to 0600 immediately after
  creation (close the TOCTOU window: `Listen` then `os.Chmod` before
  returning to caller), parent-dir creation mode 0700 if absent, and
  stale-socket-file cleanup (remove and retry bind once if `bind: address
  already in use` AND no live process holds the socket — probe by attempting
  a connect first; do not blindly unlink a socket a running daemon owns). A
  separate small `DefaultSocketPath() (string, error)` helper resolves the
  real `~/.simurgh/simurghd.sock` via `os.UserHomeDir()` for production
  callers (`cmd/simurgh/daemon.go`) — keep it in `cmd/simurgh`, not
  `internal/ipc`, so the framing/socket package stays fully path-injected
  and unit-testable like `internal/store`.
- `internal/ipc/socket_test.go` (new)
- `internal/ipc/server.go` (new) — `Server` type: accept loop, one connection
  goroutine per client, decode `Request` frames via M0.2a `Decoder`, dispatch
  by `method` string through a `map[string]HandlerFunc`, encode `Response`
  frames via M0.2a `Encoder`. Register exactly one handler: `daemon.ping` →
  `{"ok":true,"result":{"pong":true,"pid":<os.Getpid()>}}`. Any other method
  name → typed `METHOD_NOT_FOUND` error response (code/message/fix triple;
  fix = `simurgh doctor`). Malformed-frame decode errors close that
  connection after best-effort error response (do not crash the daemon on
  one bad client). Context-cancellable `Serve(ctx)` for graceful shutdown on
  SIGINT/SIGTERM.
- `internal/ipc/server_test.go` (new) — real `net.Listen("unix", ...)` on a
  `t.TempDir()` socket path (not a mock), a real client dial, request/response
  round trip for `daemon.ping`, unknown-method error shape, and two
  concurrent clients hitting the same listener without cross-talk.
- `internal/ipc/client.go` (new) — `Dial(ctx, socketPath, logPath string)`
  (both explicit, injected — same convention as `Listen`): connect to
  `socketPath`; on `ENOENT`/`ECONNREFUSED`, spawn `os.Executable()` (resolved
  path of the currently running `simurgh` binary — do not hardcode `"simurgh"`
  and rely on `$PATH`) with args `daemon run`, detached
  (`Setsid`/`Start` + no wait, stdout/stderr redirected to `logPath`), then
  retry the dial once after a bounded poll (e.g. up to 2s, short interval)
  for the socket to appear and accept. If the retry also fails, return a
  typed error with the daemon-not-running code/message/fix triple (fix:
  `simurgh daemon run`). Exactly one spawn attempt total — no retry loop
  beyond the single documented retry. `cmd/simurgh` callers pass the real
  `~/.simurgh/simurghd.sock` and `~/.simurgh/logs/simurghd.log` via the same
  `DefaultSocketPath()`-style helper.
- `internal/ipc/client_test.go` (new) — auto-start path exercised against a
  fake `simurgh`-shaped helper binary the test builds
  (`go build -o $TMP/simurgh ./testdata/fakedaemon` or `os.Executable`
  override via a package-level var seam), not the real daemon; assert
  exactly one spawn and one retry, not a loop.
- `cmd/simurgh/daemon.go` (new) — `simurgh daemon run` cobra/flag subcommand:
  resolves the socket path, calls `internal/ipc.Listen` + `Server.Serve`,
  blocks until SIGINT/SIGTERM, then returns exit 0. No other `daemon`
  subcommands (`status`/`stop`/`install`) in this package.
- `cmd/simurgh/main.go` — wire the new `daemon run` subcommand only; do not
  add unrelated commands.

Do not edit `internal/store`, `internal/broker`, `internal/safety`,
`internal/provisioner`, CI config, or any doc other than `docs/plans/orchestrator-state.md`
(orchestrator updates that, not the coder).

- Config file (`config.yaml`) reading.

If implementing the required behavior turns out to need any of the above,
stop and report back to the orchestrator rather than expanding scope.

## Required behavior summary

1. Socket file created at `~/.simurgh/simurghd.sock` (or `$SIMURGH_HOME`
   override for tests) with mode 0600, same-user only, no network listener.
2. `~/.simurgh` directory created mode 0700 if absent.
3. Stale socket file (no live daemon) is safely reclaimed; a live daemon's
   socket is never unlinked out from under it.
4. `daemon.ping` round-trips over a real Unix socket connection using the
   M0.2a protocol exactly (no protocol changes).
5. Unknown methods produce a typed error response with code+message+fix, not
   a crash or a silent close.
6. One bad/malformed frame from one client does not take down the server or
   other connections.
7. Client `Dial` auto-starts the daemon via direct spawn (never `launchctl`)
   on connection failure, retries exactly once, and fails with an actionable
   error triple if that also fails.
8. `simurgh daemon run` blocks in the foreground, serves, and shuts down
   cleanly on SIGINT/SIGTERM with exit 0.
