# M0.3 work package — state journal

## Goal

Implement the daemon-owned `state.json` persistence boundary: schema version 1, atomic same-directory rewrite, safe load behavior, and a narrow reconciliation seam for the later daemon startup flow. This package does not implement lease business rules or call `simctl`.

## Source requirements

- `docs/ROADMAP.md:23-24` defines the package.
- `docs/ARCHITECTURE.md:101-105` requires `state.json`, atomic temp-write + rename on every mutation, `schemaVersion: 1`, and startup reconciliation.
- `docs/ARCHITECTURE.md:36-45` requires the daemon to remain the single writer and preserves location transparency.
- `docs/ARCHITECTURE.md:286-290` forbids SQLite and speculative plugin/network abstractions.

## Exact write-set

- `internal/store/store.go`
- `internal/store/store_test.go`
- `internal/store/doc.go` only if its package documentation must be corrected

Do not edit `go.mod`, `cmd/**`, other internal packages, CI, or docs.

## Required behavior

- Expose a small store rooted at an injected state-file path so tests never touch the real `~/.simurgh` directory.
- Persist a JSON envelope with `schemaVersion: 1`. Keep the M0 payload minimal and do not invent broker policy or duplicate the full future lease model.
- Write atomically using a temporary file in the destination directory, flush/close it, then rename over the journal. Create the parent directory with owner-only permissions. Clean up failed temporary files without using `os.RemoveAll`.
- Load a missing journal as a valid empty schema-v1 state. Reject corrupt JSON and unsupported schema versions without overwriting the existing file.
- Provide a used, testable reconciliation seam suitable for the daemon startup sequence; M0 reconciliation itself must be a documented no-op and must not invoke Apple tooling.
- Keep all APIs deterministic and race-safe for the daemon's single-writer contract. No global mutable state.
- Add focused tests for missing-state initialization, round-trip persistence, replacement of an existing journal, corrupt JSON, unsupported schema, reconciliation invocation, permissions, and preservation of the last valid journal on a failed save.
