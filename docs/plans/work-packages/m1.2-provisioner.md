# M1.2 work package — real simctl provisioner

## Goal

Implement the real `simctl`-backed `internal/broker.Provisioner`: clone a
base device → rename to `simurgh-clone[<lease-id>:<model>:<runtime>]` → boot
→ wait for `Booted`. Runtime resolution (omitted runtime → newest installed
matching runtime). Provision-failure returns a typed error with a retry
hint. No deletion anywhere in this package.

## Exact write-set

- `internal/provisioner/simctl.go` (new) — a small `SimctlClient` interface
  this package depends on, e.g.:
  `type SimctlClient interface { ListDeviceTypes(ctx) ([]DeviceType, error);
  ListRuntimes(ctx) ([]Runtime, error); ListDevices(ctx) ([]Device, error);
  Clone(ctx, sourceUDID, newName string) (udid string, err error); Rename(ctx,
  udid, newName string) error; Boot(ctx, udid string) error; WaitBooted(ctx,
  udid string) error }` — model this on whatever real `simctl` subcommands
  are needed (`simctl list devicetypes/runtimes/devices -j`, `simctl clone
  <source> <name>`, `simctl rename <udid> <name>`, `simctl boot <udid>`,
  `simctl bootstatus <udid> -b` or polling `simctl list devices -j` for
  state `Booted`). A real implementation (`execSimctlClient`, using
  `exec.CommandContext`) lives in this file; it's the ONLY place in this
  package that shells out.
- `internal/provisioner/simctl_test.go` (new, optional) — thin tests over
  JSON-parsing helpers only (parsing `simctl list -j` output shapes), not
  over the real `exec.Command` path (that's covered by the `[mac]` suite).
- `internal/provisioner/provisioner.go` (new) — `Provisioner` type
  implementing `broker.Provisioner` (import `internal/broker` for the
  `DeviceSpec`/`Device` types — this is the expected one-directional
  dependency: `provisioner` depends on `broker`'s types, `broker` never
  depends on `provisioner`). Constructor `New(client SimctlClient) *Provisioner`.
  `Provision(ctx, spec)`:
  1. Resolve `spec.Model` to a `simctl` device-type identifier via
     `ListDeviceTypes` (exact name match; not-found → typed error, fix =
     `simurgh doctor` to list what's installed... actually there's no such
     doctor listing yet, so fix = the exact missing-device-type message
     with a hint to check `xcrun simctl list devicetypes`).
  2. Resolve `spec.Runtime`: if empty, pick the newest installed **iOS**
     runtime (semver-ish compare on the runtime's version string, or trust
     `simctl`'s own ordering — be explicit about which and test it); if set,
     exact/prefix match against installed runtimes. Not-found/not-installed
     → typed error, fix = exact `xcodebuild -downloadPlatform iOS` string.
  3. Find or determine the **base device** for that (device-type, runtime)
     pair (a plain, un-suffixed simulator `simctl create`'s if none exists
     yet with that exact type+runtime — do not reuse an arbitrary existing
     device the user created by hand; only reuse a device this package
     itself previously created as a base, tracked by a stable predictable
     name like `simurgh-base[<model>:<runtime>]` so re-runs are idempotent
     — note: this pattern must NOT collide with the `simurgh-(clone|warm)`
     deletion-invariant regex, since the base device must never be
     considered clone/warm-deletable by the future reaper; document this
     distinction clearly in a comment since it's safety-invariant-adjacent).
  4. Clone the base device with a temporary name, rename to
     `simurgh-clone[<lease-id>:<model>:<runtime>]` (the caller must pass the
     lease ID into `Provision` — **this changes the `Provisioner` interface
     signature**: add `LeaseID string` as a `Provision` parameter or a field
     on a small `ProvisionRequest{Spec DeviceSpec; LeaseID string}` struct.
     This is a deliberate, small, backward-incompatible signature change to
     `internal/broker/provisioner.go` and `internal/broker/broker.go`'s call
     site — include it in this package's write-set as the one permitted
     edit to `internal/broker` — see below).
  5. Boot the clone, wait for `Booted` state (bounded poll, e.g. up to 60s,
     short interval; timeout → typed error, fix = "check `xcrun simctl list
     devices` for a stuck boot").
  6. Return `Device{UDID, Name, Runtime, CloneOf: <base UDID>, Booted: true}`.
  Every failure path returns one of a small set of typed errors
  (`DeviceTypeNotFoundError`, `RuntimeNotFoundError`, `CloneFailedError`,
  `BootTimeoutError`) each with a code/message/fix triple, duplicating the
  local-error-triple pattern from `internal/broker/errors.go` (do not
  import `internal/ipc` here either, for the same transport-agnostic
  reason — but importing `internal/broker` for `DeviceSpec`/`Device` is
  fine and expected, per the one-directional dependency above).
- `internal/provisioner/provisioner_test.go` (new) — unit tests against a
  **fake `SimctlClient`** (no real `simctl` calls): successful
  clone-and-boot returns correct `Device` fields and exact name pattern;
  missing device type → typed error; missing runtime → typed error with
  the exact `xcodebuild -downloadPlatform` fix string; boot timeout →
  typed error; idempotent base-device reuse (call `Provision` twice with
  the same spec, fake asserts `Clone` was NOT called against a freshly
  `create`'d base the second time — the base is reused, not recreated).
- `internal/provisioner/integration_test.go` (new) — `//go:build darwin_sim`
  tagged real integration test using `execSimctlClient` against this actual
  Mac: provisions one real clone from `DeviceSpec{Platform:"iOS",
  Model:"iPhone 17 Pro"}` (omit runtime — exercise the resolution path),
  asserts it reaches `Booted`, asserts the name matches
  `^simurgh-clone\[.*\]$`, then **the test itself shuts down and deletes
  only that exact UDID it just created** as final cleanup (a raw
  `exec.Command("xcrun","simctl","delete",udid)` inline in the test — this
  is test-only cleanup of an artifact the test itself created in the same
  run, not product code, and does not need to route through the
  not-yet-built `internal/safety`; document this distinction in a comment).
  Skip cleanly (`t.Skip`) if no iOS runtime is installed.
- `internal/broker/provisioner.go` — the one permitted edit outside
  `internal/provisioner`: change the interface to accept the lease ID
  (`Provision(ctx, ProvisionRequest) (Device, error)` or add a `LeaseID`
  parameter — pick whichever reads cleaner, document the choice).
- `internal/broker/broker.go` — update the one call site
  (`finishProvision`) to pass `lease.ID` through. **Do not change any other
  broker behavior** — this is a mechanical signature threading, not a
  broker redesign.
- `internal/broker/broker_test.go` — update the existing fake `Provisioner`
  in this test file to match the new signature. **Do not change what the
  existing tests assert**, only the fake's method signature.
- `internal/provisioner/doc.go` — package comment.

Do not edit `internal/store`, `internal/ipc`, `internal/safety`,
`internal/watcher`, `internal/reaper`, `internal/cli`, `cmd/simurgh`, CI

## Explicitly out of scope

- Any deletion of a device that was NOT created by the current call (no
  `simctl delete|erase` outside the integration test's self-cleanup of its
  own artifact).
- Warm template creation/selection/reuse (`simurgh-warm[...]`) — M2.
- Isolation environment / DerivedData / env emission — M2.
- Watcher/reaper/reclamation — M1.3.
- `internal/safety` — M1.4. This package must remain safe enough that
  safety's future guards are a belt-and-suspenders addition, not a
  dependency this package needs to function correctly today.
- CLI/IPC/MCP wiring.
- Physical devices (`devicectl`) — explicitly deferred product-wide.

If implementing the required behavior turns out to need any of the above,
stop and report back to the orchestrator rather than expanding scope.

## Risk class

`low` — no deletion in product code, public `simctl` interfaces only, the
one destructive call in this whole work package is the integration test's
own self-cleanup of a device it created in the same test run (not reachable
from any product code path). Standard review pipeline (fresh cross-model
review). If the reviewer finds any path where this package could plausibly
delete or mutate a device it did not just create, treat that as
**blocking**, not minor — re-classify as sensitive and escalate.
