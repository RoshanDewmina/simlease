# M1.5b work package — CLI client commands

## Goal

Implement the CLI client commands that consume M1.5a's daemon RPCs:
`simurgh acquire|release|renew|status|list`, all thin IPC clients (no
business logic — the daemon owns all of that). This is what makes the
product actually usable from a terminal for the first time.

## Source requirements

- `docs/ARCHITECTURE.md:223-246` (§9 CLI surface), quoted for the subset
  this package implements:
  ```
  simurgh acquire --model "iPhone 17 Pro" [--runtime 27.0] [--label k=v]...
          [--ttl 30m] [--reuse-if-exists] [--wait] [--rm]
          [--inactivity-timeout 10m] [--hard-timeout 3h] [--json]
  simurgh release [<lease-id>] [--all --label k=v]
  simurgh renew <lease-id> [--ttl 30m]
  simurgh status [--queue] [--json]        # pool + leases overview
  simurgh list [--label-selector k=v,...]  # leases (Limrun-style selectors)
  ```
  `simurgh env`, `simurgh exec`, `simurgh warm`, `simurgh prune`,
  `simurgh init`, `simurgh mcp` are **out of scope** — M2/M3 territory.
  Conventions: no lease-id argument → most recent lease owned by caller
  (pointer in `~/.simurgh/last-lease`) · `--json` on every command · exit
  codes: **0 ok, 2 queued/blocked (with structured reason on stdout), 3
  invalid input, 4 environment problem, 5 internal.**
- `internal/ipc.Dial(ctx, socketPath, logPath)` (existing, M0.2b) — every
  command dials through this, not a raw `net.Dial`, so the daemon
  auto-starts on first use per its existing behavior. Do not reimplement
  auto-start logic in this package.
- `internal/daemon` (existing, M1.5a) — the six `lease.*` methods this
  package calls. **Honesty note, do not paper over it:** `AcquireRequest.
  ReuseIfExists` is wired end-to-end (CLI flag → wire JSON → broker field)
  but `internal/broker.Acquire` does not currently implement reuse
  semantics (a known, already-logged gap from M1.1 — the field is stored
  but never read). Wire `--reuse-if-exists` through faithfully anyway (so
  the flag and wire contract are future-proof) but note in a doc comment
  on the CLI command AND in your final report that it is currently a
  no-op server-side — do not claim it works.

## Exact write-set

- `internal/daemon/daemon.go`, `internal/daemon/daemon_test.go` — ONE
  additive IPC method beyond M1.5a's six: `pool.status`, needed for
  `simurgh status`'s "pool + leases overview." Handler returns
  `{"capacity": <int>, "leases": {"queued": N, "provisioning": N,
  "active": N, "released": N, "cancelled": N, "failed": N, "reclaimed":
  N}}` — counts derived from `deps.Broker.List(ListFilter{})` grouped by
  `State`, plus `deps.Broker.Capacity()` (already a public method). No new
  broker method needed. Add this handler alongside the existing ones in
  `RegisterLeaseHandlers` (or a small sibling registration function if
  that reads cleaner — your call, keep it simple) and a focused test.
- `cmd/simurgh/lease.go` (new) — the CLI commands. Match the existing
  `cmd/simurgh/daemon.go`/`doctor.go` style (flat functions, no cobra/
  cli-framework dependency added — this repo has none yet and this
  package should not be the one to introduce it; hand-rolled `os.Args`
  parsing like `main.go` already does is fine and consistent):
  - `simurgh acquire`: flags `--model` (required), `--runtime`, `--label
    k=v` (repeatable, `map[string]string`), `--ttl`, `--reuse-if-exists`,
    `--wait`, `--rm` (maps to `ReleaseOnPIDExit`), `--inactivity-timeout`,
    `--hard-timeout`, `--json`. Sends `lease.acquire` with `owner.pid =
    os.Getpid()`, `owner.agent` = a fixed string like `"simurgh-cli"` (no
    way to know the *real* calling agent from a bare CLI invocation — note
    this as a known limitation, future `simurgh init`/env-var-based agent
    identification is out of scope here). On success: writes the lease ID
    to `~/.simurgh/last-lease` (honors `$SIMURGH_HOME` the same way
    `DefaultSocketPath` does — add a `DefaultLastLeasePath()` helper next
    to the existing `Default*Path` helpers in `daemon.go`), prints the
    lease (JSON if `--json`, else a short human summary: id, state, model,
    UDID if present), exits 0. On `CAPACITY_QUEUED`: prints the queue
    position/reason, exits 2. On `DAEMON_NOT_RUNNING` (from `ipc.Dial`
    itself, not a lease error) or a `PROVISION_FAILED` lease error: exits
    4. On missing `--model` or any other malformed flag: exits 3 without
    even dialing the daemon. Any other unexpected error: exits 5.
  - `simurgh release [<lease-id>]`: no-arg → read `~/.simurgh/last-lease`
    (missing file → exit 3, "no lease-id given and no last-lease pointer
    found, fix: pass a lease-id or run `simurgh acquire` first" — an
    actual error triple, not a bare Go error). `--all --label k=v` releases
    every lease matching the label selector (calls `lease.list` first,
    then `lease.release` per match, best-effort — report a summary of
    how many succeeded/failed, non-zero exit if any failed). `LEASE_NOT_
    FOUND`/`INVALID_STATE` → exit 3. Success → exit 0.
  - `simurgh renew <lease-id> [--ttl 30m]`: lease-id required as a
    positional arg here (unlike release/renew's "no-arg = last lease" —
    actually re-check the architecture snippet: `renew <lease-id>` has no
    bracket, so it IS required per the documented surface; still support
    empty → last-lease fallback for consistency with release/renew's
    Limrun-derived UX pattern **only if** you can justify it from the
    doc — if the doc shows it as required, keep it required and do not
    invent a fallback the spec doesn't ask for). Same error-triple/exit
    mapping pattern as release.
  - `simurgh status [--queue] [--json]`: calls `pool.status`; `--queue`
    additionally calls `lease.list` filtered/sorted to just QUEUED leases
    and prints their positions (position isn't stored on the Lease type
    itself — you may need to approximate via list order, or note in a
    comment that exact queue position per lease isn't exposed by any
    current RPC beyond what `CAPACITY_QUEUED` returns at acquire-time;
    document whichever approximation you pick, don't silently fake exact
    numbers). Exit 0 always (a status query is not itself queued/blocked).
  - `simurgh list [--label-selector k=v,...]`: calls `lease.list` with the
    parsed selector, prints a table (id, state, model, udid) or JSON.
    Exit 0.
  - Shared helpers: a `dialAndCall(ctx, method string, params any) (json.
    RawMessage, error)` used by every command (dial via `ipc.Dial` with
    `DefaultSocketPath()`/`DefaultLogPath()`, encode/decode via
    `internal/ipc`), and an exit-code classifier
    `exitCodeForIPCError(err error) int` implementing the 0/2/3/4/5
    contract above from an `*ipc.Error`'s `Code` field (switch on the
    known codes: `CAPACITY_QUEUED`→2, `LEASE_NOT_FOUND`/`INVALID_STATE`→3,
    `PROVISION_FAILED`/`DAEMON_NOT_RUNNING`→4, everything else→5).
- `cmd/simurgh/lease_test.go` (new) — unit tests for the pure/testable
  parts only: flag parsing (labels, durations), the exit-code classifier
  function, and `DefaultLastLeasePath()`'s `$SIMURGH_HOME` honoring — do
  NOT attempt to unit-test the full dial-a-real-daemon flow here, that's
  covered by the live check below and by `internal/daemon`'s own tests.
- `cmd/simurgh/main.go` — wire the five new subcommands (`acquire`,
  `release`, `renew`, `status`, `list`) alongside the existing `daemon`/
  `doctor`/`help`.

Do not edit `internal/broker`, `internal/provisioner`, `internal/watcher`,
`internal/reaper`, `internal/safety`, `internal/ipc`, `internal/cli`, CI
config, or any doc other than `docs/plans/orchestrator-state.md`. The one
permitted edit outside `cmd/simurgh` is the additive `pool.status` handler
in `internal/daemon`.

## Explicitly out of scope

- `simurgh env`, `exec`, `warm`, `prune`, `init`, `mcp` — later milestones.
- Implementing real `ReuseIfExists` semantics in the broker — that's a
  broker change, not this package's job; wire the flag faithfully and be
  honest that it's currently inert.
- Exact per-lease queue position display beyond what's already returned by
  a `CAPACITY_QUEUED` error at acquire time (see the `status --queue` note
  above).
- Any new cli-framework/flag-parsing dependency.

   `xcrun simctl delete <udid>` as your own test cleanup, confirm final
   state shows only the pre-existing `simurgh-base[...]`. Also test one
   failure path live: `simurgh renew nonexistent-lease-id` and confirm
   exit code 3.

Return verbatim output, changed files, diff stat, and explicitly restate
the `ReuseIfExists` no-op caveat in your final report.

either, matching M1.5a's existing behavior). Standard review pipeline.
