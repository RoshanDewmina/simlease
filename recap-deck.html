03 — B2 4 agents · real bug found

A real daemon bug, found and fixed

Symptom
Stuck queue
2 leases sat QUEUED for 20+ minutes with capacity fully idle — active: 0.
20+ min hang
Root cause
No retry
A Release()-triggered promotion that loses to a transient RAM-pressure dip has no other trigger to retry once pressure recovers.
canGrantLocked
Fix
RetryQueues
New Broker.RetryQueues, wired into the daemon's existing 5s reclaim loop. Regression test reproduces the exact race.
commit 058a101

Root cause, not a CPU count
